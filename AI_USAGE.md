# 🤖 AI Usage

This file states how AI tools were used in the OpenBatt projects, so users and reviewers can judge the work with that in mind.

## Tool

**Claude** (Anthropic), used through Claude Code as a coding assistant.

| Model | Effort |
|-------|--------|
| Opus 5.x | medium |
| Sonnet 5.x | medium |

## How AI was used

AI was used as an assistant, not as an author on its own. The OpenBatt team set the goals, made every design decision, and reviewed every change before it was kept. AI assisting did not change program or functional logic.

In firmware development AI was used for:

- **Code cleanup** - keeping one code style across the firmware.
- **Naming** - consistent naming of functions, macros and variables.
- **Comments** - cleaning up and shortening code comments.
- **Code reviews** - finding bugs and weak spots. The team decided which findings to fix.

AI was also used for:

- **Documentation** - formatting, cleaning, grammar check and generating diagrams.
- **Analysis** - evaluating test logs, and comparing the algorithms with published papers and public battery datasets.

## Where AI was not used

- Hardware design.
- Project goals, requirements, algorithm choices and architecture decisions.
- Code generated by ST tools (CubeMX, HAL, CMSIS) and the microcontroller configuration.
- Building, flashing and testing on real hardware, including measurements on real battery packs.
